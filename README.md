# GIA-FVRNG · 大数计算过程混淆器

把一个**任意位数的常量**替换成一段**在运行时精确还原该常量的运算过程**，
使得源码（及编译产物）中不再出现该常量的字面量形式。

这是一种标准的、双用途的代码混淆 / 软件保护技术，常见于：防常量提取、
反逆向教学、CTF 题目构造、常量白盒化研究等。请仅在你有权处理的代码上使用。

---

## 它做什么

输入一个十进制非负大整数 `T`，输出：

1. 一棵**运算表达式树**，对其求值恒等于 `T`；
2. 一份**可直接编译运行的自验证 C++ 程序**，其源码里没有 `T` 的字面量，
   运行时通过那串运算把 `T` 还原出来，并与期望值比对打印 `[OK]`。

例如把 `123456789012345678901234567890` 混淆成（节选）：

```cpp
badd(bmul(C("10"), badd(badd(bmul(C("2"), badd(bor(bshl(badd(C("1534761"),
C("3206906")), 65), ... )), ... )), ...)), C("0"))
```

字面量全是无意义的中间数，真正的目标值只在运行时涌现。

---

## 核心思想：用“恒等分解”取代“搜索”

本仓库的**前身**用遗传算法去**搜索**一串能凑出目标值的运算。搜索有两个
根本问题：可能不收敛（于是返回一个**近似的、错误的**表达式），且只支持
`long long`、运算数被限制在 `[10,100]`，`S_pow` 还用浮点 `pow` 导致整数结果出错。

重写后改用**可逆的恒等变换递归展开**。每一步都是代数恒等式，所以**构造上**
就保证“求值 == 目标”，与数字大小无关，永不返回错误解：

| 分解 | 恒等式 | 选取方式 | 规模趋势 |
|------|--------|----------|----------|
| ADD    | `T = A + B`            | `A` 随机，`0<A<T`，`B=T−A`        | 收敛（子目标变小） |
| MULADD | `T = f·Q + R`          | `f` 为小因子，`Q=T/f`，`R=T%f`    | 收敛 |
| SPLIT  | `T = (H << k) \| L`    | `H=T>>k`，`L` 为 `T` 低 `k` 位    | 收敛 |
| XOR    | `T = A ^ B`            | `M` 随机，`A=M`，`B=T^M`（自逆）  | 等位宽 |
| SUB    | `T = A − B`            | `B` 随机`>0`，`A=T+B`             | 放大 |

对每个子目标递归选择一种分解，直到 `depth`（深度预算）用尽或子目标足够小
（`< 256`）时落为字面量叶子。`depth==1` 时只用收敛型分解，避免产生过大的单个
字面量。XOR/SUB 这类“等宽/放大”变换用于增加混淆层次，其膨胀由 `depth` 封顶。

> 位运算（`&` `|` `^` 和移位）只作用在**非负数**上，整个分解过程也只产生
> 非负中间值，因此语义清晰、与生成代码的计算完全一致。

### 两重正确性保证

- **生成期自检**：生成器对表达式树独立求值一次，断言等于目标（见输出 `自检 verify`）。
- **运行期自验证**：生成的程序重新计算一遍并与期望值比对，打印 `[OK]` / `[FAIL]`。

## 代码结构

| 文件 | 作用 |
|------|------|
| `Generater/BigInt.hpp`     | 任意精度有符号大整数（基 `2^32` 小端）：加减乘、除/模（二进制长除）、移位、位运算、十进制 I/O、带拒绝采样的随机数。生成器与生成代码共用。 |
| `Generater/Obfuscator.hpp` | 恒等分解引擎 + 表达式树（`Node`）+ 代码生成 + 自验证程序生成。 |
| `Generater/Generater.cpp`  | 命令行入口。 |

仅用标准 C++17，无平台相关代码：MSVC v143 与 g++/clang 均可编译。

## 构建与使用

**Visual Studio**：打开 `Generater.sln`，直接生成运行。

**命令行（g++/clang）**：

```bash
cd Generater
g++ -std=c++17 -O2 Generater.cpp -o Generater

# 用法: Generater [target] [depth] [seed] [outfile]
./Generater 123456789012345678901234567890 6 42 obfuscated_output.cpp

# 编译并运行生成的自验证程序（需与 BigInt.hpp 同目录）
g++ -std=c++17 -O2 obfuscated_output.cpp -o demo
./demo          # => computed = 123...890 / [OK] matches target
```

参数：

- `target`：十进制非负大整数，任意位数（已验证 800+ bit）。
- `depth`：递归深度，越大表达式越庞杂（节点数大致指数增长）。默认 `6`。
- `seed`：随机种子。**相同参数 + 相同种子 ⇒ 完全可复现**；换种子得到不同形态。默认 `0xC0FFEE`。
- `outfile`：输出的自验证程序路径。默认 `obfuscated_output.cpp`。

## 说明与边界

- 这是**常量（计算过程）混淆**，不是加密：掌握该技术者可将表达式求值还原出常量，
  它提高的是静态提取常量的成本，而非提供保密性。
- 分解本身是公开算法；真正影响形态的是随机种子。
- 位运算与移位基于非负整数的二进制表示定义。
